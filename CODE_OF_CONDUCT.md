# Code of Conduct

lights-out follows the
[CNCF Community Code of Conduct, version 1.3](https://github.com/cncf/foundation/blob/main/code-of-conduct.md),
in every project space: issues, pull requests, discussions, reviews, and
anywhere someone speaks for the project.

## Reporting

lights-out is not a CNCF project, so the CNCF committees named in that
text do not handle its reports. Reports go through GitHub; the project
publishes no email address.

- **To the maintainers:** open an issue titled **"conduct contact
  request"**, with no details and no names in it. A maintainer answers
  there with a private way to talk, and you report there. Only the
  maintainers in [MAINTAINERS.md](MAINTAINERS.md) read what you send.
- **To GitHub**, which enforces its own
  [Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines)
  here: the **Report content** item in the menu of any issue, pull
  request or comment, then **Report abuse to GitHub Support**, or the
  [report abuse form](https://github.com/contact/report-abuse). Use it
  when you would rather not go through the maintainers, or when the
  report concerns one of them.

You get a first answer within 14 days. Your report is kept confidential,
and nothing about it is published without your consent. A maintainer who
is the subject of a report takes no part in handling it.

The maintainers decide what action is appropriate, as the Code of Conduct
describes, and tell the reporter what was decided.
