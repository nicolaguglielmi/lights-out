**lights-out 0.9.0** adds `M65`–`M97`: verification from the proxy, one install, init drafting the plane half, more stacks, the unified CLI, the ADR lifecycle, signed provenance, epics and spec split, the self-healing loop, the modular console with OIDC roles, managed GCP adapters, the jury across providers, a conformance suite for every port, the reviewer's catch rate and a read-only portfolio. The `.lights-out/` contract is frozen at schema `v1.0` (ADR 0138). What has not been run live is listed at the end.

### Install

One install, no clone needed to gate a repository:

```sh
uv tool install lights-out-gates==0.9.0
```

Quick start on an existing repository:

```sh
lights-out start
lights-out init --apply
lights-out verify
```
