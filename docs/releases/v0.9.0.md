**lights-out 0.9.0** completes the Enterprise Autonomous Software Farm milestones (`M72`–`M89`), introduces the Cross-Provider Jury (`M37`), the one-command `./go` demo-loop (`M38`), external `outside/<name>` `AgentHarness` admission, zero shell-boundary debt in `core/`, live L1/Map preflight tooling, and one-command installation shipping both `lights-out` and `lights-out-gates` together.

- **One install via `lights-out-gates`** ([ADR 0099](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0099-one-install-via-lights-out-gates.md)). `uv tool install lights-out-gates` now ships both the POSIX `lights-out` container wrapper (with `--version`) and the containerless stdlib `lights-out-gates` (`--light`) CLI in one distribution, verified inside the built wheel and on `stranger`.
- **Unified power-user CLI, zero-copy `init --apply`, and terminal cockpit (`M72`–`M74`)** ([ADR 0112](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0112-unified-cli-grammar-json-and-completions.md), [ADR 0113](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0113-zero-copy-init-apply-and-incremental-baseline.md), [ADR 0114](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0114-interactive-terminal-cockpit-tui.md)).
  - `lights-out <domain> <verb>` (`repo`, `ticket`, `release`, `ops`, `config`, `completion`) brings wrapper parity with `./go`, POSIX flags, `--json`/`--jsonl` envelopes, exit codes `0`–`4`, and `bash`/`zsh`/`fish` completions while preserving flat commands and the one-line gate contract.
  - `./go init --apply` drafts and optionally commits `.lights-out/` zero-copy into attached repositories (`--branch`, `--commit`, `--force`), paired with `--baseline-mode incremental` for large legacy codebases.
  - `./go top` (`lights-out top`) adds a zero-dependency `curses` TUI with five live views, `ETag` polling, and `--once`/`--json` non-TTY modes.
- **Full governance and traceability (`M75`–`M77`)** ([ADR 0115](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0115-autonomous-adr-lifecycle-and-policy.md), [ADR 0116](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0116-tracker-conformance-and-external-adapters.md), [ADR 0117](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0117-signed-agent-provenance-attestations.md)).
  - Autonomous ADR lifecycle checks (`./go adr-check`, `RISK_REQUIRE_ADR=off` opt-in policy) and role guidance for structural diffs.
  - Six-case `Tracker` port conformance (`./go tracker-conformance`), bidirectional `sync.sh`, and `github-issues` / `linear` adapters alongside `outside/<name>` tracker admission.
  - `cosign`-signed in-toto `Statement/v1` provenance attestations (`./go provenance`) binding commit/image digests, ticket specs, ADR SHA-256 digests, spend, gate verdicts, and `go-for-launch`, linked additively in release evidence packs.
- **Greenfield genesis, Epic DAGs, autonomous spec-split, and parallel fleet (`M78`–`M80`)** ([ADR 0118](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0118-greenfield-app-builder-genesis.md), [ADR 0119](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0119-epics-dag-and-multi-service-monorepos.md), [ADR 0120](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0120-auto-spec-split-parallel-fleet-and-m24-harness.md)).
  - `./go genesis` scaffolds an empty repository and brief into ADR `0001`, stack starter code, baseline tests, `Containerfile`, `.lights-out/` contract, and initial backlog.
  - `./go epics` manages `depends_on` ticket DAG waves with automatic downstream unblocking on `main-green` and coordinated `--workspace` monorepo manifests.
  - `./go spec-split` (`INTAKE_NETWORK_SPLIT=on`, `NETWORK_AUTO_SPLIT=on`) proposes disjoint `impl`/`tests` network perimeters; `./go watch --workers 1..8` dispatches disjoint tickets concurrently while `ReleaseTrainLock` serializes `merge`/`mainline`/`release`; `./go m24-check` evaluates multi-provider benchmarks deterministically while keeping unexecuted `openai` and `zai` runs honestly marked `not_run`.
- **Closed self-healing, enterprise observability, and migration safety (`M81`–`M83`, `M38`)** ([ADR 0121](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0121-closed-deterministic-self-healing-loop.md), [ADR 0122](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0122-enterprise-observability-probes-and-charts-port.md), [ADR 0123](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0123-database-expand-contract-migration-gate.md)).
  - Bounded redacted rollback log/exemplar capture, automatic post-mortem ticket perimeters, policy-gated triage mitigation (`AUTO_MITIGATE_ON_TRIAGE=off`), and the closed M38 demo-loop (`./go` `demo-loop`, [ADR 0132](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0132-closed-self-healing-demo-loop.md)) running the full L0 self-healing cycle (`alert -> rollback -> postmortem -> ticket -> gates -> canary -> 100% + provenance + frozen console`) in one cold zero-key command.
  - Continuous stage `smoke.sh` probing, saturation/restart/burn-rate SLO checks, W3C `trace:` anchors, and the five-case `Charts` conformance suite (`./go charts-conformance`) with `grafana` and `cloud-monitoring` adapters.
  - `./go migration-safety` checks changed SQL, Python, and Ruby migrations for rollback-unsafe DDL (`DROP`, `TRUNCATE`, `RENAME`, un-defaulted `NOT NULL`) unless anchored to an expand commit.
- **Modular SSE workstation console and adaptive Guided vs. Cockpit UX (`M84`–`M86`)** ([ADR 0124](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0124-modular-console-build-and-sse-streaming.md), [ADR 0125](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0125-control-plane-web-workstation.md), [ADR 0126](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0126-adaptive-persona-ux-and-impeccable-polish.md)).
  - Nine modular `console/src/` sources bundle deterministically via `./go console-build` into zero-CDN `console/index.html`, paired with authenticated `GET /v1/events` SSE streaming in live mode and zero SSE in snapshots.
  - `Cmd+K` command palette, authenticated control actions (`init`, `assign`, `resume`, `rollback`, `freeze`), Epic DAG and ADR viewers, PR diff/mutant panel, canary charts, and `Guided` (junior) vs. `Cockpit` (senior) adaptive persona modes verified across light/dark WCAG AA themes and desktop/mobile viewports.
- **Cryptographic OIDC/RBAC, managed L2/L3 cloud adapters, and polyglot enterprise stacks (`M87`–`M89`)** ([ADR 0127](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0127-cryptographic-oidc-jwt-and-console-rbac.md), [ADR 0128](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0128-managed-l2-l3-cloud-adapters-and-live-conformance.md), [ADR 0129](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0129-polyglot-enterprise-stacks-and-hygiene.md)).
  - Pure-stdlib RS256/ES256/HS256 + JWKS JWT verification and four-tier RBAC (`viewer`, `developer`, `operator`, `launcher`) with redacted audit logging in `console/serve.py`.
  - Managed L2/L3 GCP adapters (`pubsub`, `firestore`, `artifact-registry`, `managed-prometheus`, `cloud-deploy`, `cloud-workflows`) with stdin-only Bearer auth and fork-safe keyless OIDC nightly conformance (`.github/workflows/cloud-conformance.yml`), verified locally against HTTP/CLI mocks.
  - Five new stack runners (`dotnet`, `kotlin`, `swift`, `php`, `ruby`), 36-shape `./go corpus`, `outside/<name>` `EventBus` conformance, and retired `ci/` shell debt.
- **Cross-Provider Jury, external `AgentHarness`, and zero `core/` shell debt (`M37`, `M90`)** ([ADR 0130](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0130-cross-provider-jury-and-outside-harness.md), [ADR 0131](https://github.com/nicolaguglielmi/lights-out/blob/v0.9.0/docs/adr/0131-retire-core-shell-boundary-debt.md)):
  - Cross-Provider Jury (`auto` mode by default) deterministically routes `medium`/`high` risk PR reviews to an alternate configured vendor when two or more provider keys are available, recording jury metadata in provenance receipts.
  - External `outside/<name>` `AgentHarness` admission joins the conformance-gated outside adapter lifecycle alongside `fixtures/outside-adapters/` and external orchestrator recipes.
  - All ten remaining `core/` shell-boundary debt scripts migrated to stdlib Python modules, retiring `core/` shell debt in `ci/shell-boundary.sh` to zero while preserving every script entrypoint and gate contract.
