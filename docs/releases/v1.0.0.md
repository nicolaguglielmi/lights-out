**`lights-out` `v1.0.0`** completes 25 milestones (`M72`–`M89` shipped in `v0.9.0` plus `M91`–`M97` across Sprints 6–7) and stabilizes the hexagonal `.lights-out/` workload contract as `v1.0`.

### Install

Single install — no separate clone required to gate any repository:

```sh
uv tool install lights-out-gates==1.0.0
```

Quick start on an existing repository:

```sh
lights-out start
lights-out init --apply
lights-out verify
```
